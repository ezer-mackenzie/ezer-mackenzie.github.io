# Code of Conduct

This project follows the Contributor Covenant code of conduct. We value the participation of every contributor and want an open and welcoming environment.

Key points:

- Be respectful and considerate in all interactions.
- Do not harass or discriminate based on identity or background.
- When giving feedback, be constructive and kind.

If you experience or witness unacceptable behavior, please report it to the project maintainers at: conduct@ezer-mackenzie.github.io

For the full policy, see the Contributor Covenant v2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

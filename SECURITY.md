# Security Policy

If you believe you have found a security vulnerability in this project, please do not open a public issue. Instead, report it privately so we can investigate and respond responsibly.

Report a security issue by emailing: security@ezer-mackenzie.github.io

When reporting, please include:
- Affected component(s)
- Steps to reproduce
- Expected and actual behavior
- Any PoC (proof-of-concept) code, logs, or screenshots

We aim to respond within 3 business days. If you need encrypted communication, include a PGP public key in your message; the repository owner will provide a key for secure transmission on request.

After a fix is available, we will coordinate disclosure and credit with the reporter.
